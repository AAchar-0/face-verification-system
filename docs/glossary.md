# Glossary of Abbreviations

Every abbreviation used in this project, with its full form. Names such as YuNet, SFace, pandas and pytest are product names, not abbreviations.

## Face verification

| Abbreviation | Full form | Meaning here |
|---|---|---|
| FAR | False Accept Rate | How often a wrong person is wrongly accepted. The security-critical error |
| FRR | False Reject Rate | How often the right person is wrongly rejected. The inconvenience error |
| EER | Equal Error Rate | The setting where FAR and FRR are equal. A one-number summary of accuracy |
| ROC | Receiver Operating Characteristic | A curve showing how the accept and reject errors trade off as the decision threshold moves |
| LFW | Labeled Faces in the Wild | A public benchmark of web-collected face photo pairs, used locally for evaluation only |
| KYC | Know Your Customer | The identity checks that banks and financial services must perform |
| ONNX | Open Neural Network Exchange | A standard file format for trained models. The two face models are `.onnx` files |
| OpenCV | Open Source Computer Vision Library | The library that runs the face detector and recognizer |
| CLI | Command-Line Interface | A program used by typing commands in the terminal |
| RAM | Random Access Memory | A computer's short-term memory. Its contents vanish when a program ends |
| AES | Advanced Encryption Standard | The scrambling method used to encrypt the stored templates |
| JSON | JavaScript Object Notation | A plain-text format for structured data. Templates are stored as JSON before being encrypted |
| UTC | Coordinated Universal Time | The world time standard used for every timestamp, so dates are never ambiguous |
| HMAC | Hash-based Message Authentication Code | A seal that makes any change to an encrypted file detectable |
| SHA-256 | Secure Hash Algorithm, 256-bit | A fingerprint of a file. If one byte changes, the fingerprint changes |
| LFS | Large File Storage | Git's way of storing large files. The model files are kept this way |

## Law and licences

| Abbreviation | Full form | Meaning here |
|---|---|---|
| GDPR | General Data Protection Regulation | The European Union's data protection law |
| BIPA | Biometric Information Privacy Act | An Illinois (United States) law on collecting biometric data |
| DPIA | Data Protection Impact Assessment | A written risk review required before high-risk processing of personal data |
| ODPC | Office of the Data Protection Commissioner | Kenya's data protection regulator |
| MIT | Massachusetts Institute of Technology | The licence is named after it. It allows reuse if the copyright notice is kept |
| CC BY 4.0 | Creative Commons Attribution 4.0 | A licence allowing reuse of data with credit to its authors |
| CFF | Citation File Format | The `CITATION.cff` file that powers GitHub's "Cite this repository" button |

## Data, SQL and statistics

| Abbreviation | Full form | Meaning here |
|---|---|---|
| SQL | Structured Query Language | The language used to question a database |
| CTE | Common Table Expression | A named step inside a SQL query |
| CSV | Comma-Separated Values | A plain-text table file |
| EDA | Exploratory Data Analysis | Looking through data to understand it before modelling |
| MAE | Mean Absolute Error | The average size of a forecast's miss |
| RMSE | Root Mean Squared Error | An error measure that punishes large misses more |
| MAPE | Mean Absolute Percentage Error | The average miss as a percentage |
| UCI | University of California, Irvine | Hosts the machine learning repository the retail data came from |
| GBP | Great British Pound | The currency of the retail data (£) |

| URL | Uniform Resource Locator | A web address |
